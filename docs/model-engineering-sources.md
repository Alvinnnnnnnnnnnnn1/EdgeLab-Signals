# Research mechanisms and exclusions

These readings informed mechanisms and validation checks. No external implementation, dataset, figure or reported performance was imported. Our numerical results come solely from retained project data. Public documentation does not authorise a provider request.

| Primary source | Transfer and limitation |
|---|---|
| [Papageorgiou et al., basketball ML comparison](https://link.springer.com/article/10.1007/s10115-024-02092-9) | Statistic-specific model comparisons motivate modest nonlinear controls. A filtered high-performance-player study using point metrics does not validate NBA prop probabilities or betting returns here. |
| [Terner and Franks, basketball modelling review](https://www.annualreviews.org/content/journals/10.1146/annurev-statistics-040720-015536) | Partial pooling and regularisation motivate M1's exposure-weighted priors. Timestamped roles and opportunity data are still required for richer effects. |
| [Gneiting and Raftery, proper scores](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf) | Evaluate predictive distributions with CRPS/log score and disclose tail floors. Raw CRPS across differently scaled stats does not establish market superiority. |
| [Kull et al., beta calibration](https://proceedings.mlr.press/v54/kull17a.html) | Positive-coefficient beta CDF maps include identity and preserve monotonicity. Calibration requires disjoint dates; isotonic is excluded on the small independent source-clock sample. |
| [Kuleshov et al., calibrated regression](https://proceedings.mlr.press/v80/kuleshov18a.html) | Point error and interval calibration require separate evidence. We calibrate a whole discrete CDF and retain coherent line probabilities. |
| [Duan et al., NGBoost](https://proceedings.mlr.press/v119/duan20a) | Joint parameter boosting is credible research, not an automatic win. No installed suitable count learner/dependencies were found; M3 is not attempted. |
| [NBA injury report](https://www.nba.com/players/injury-report) | Source timing matters. No official injury collector was enabled; later reports cannot repair an earlier cutoff. |
| [Odds API v4](https://the-odds-api.com/liveapi/guides/v4/), [market catalogue](https://the-odds-api.com/sports-odds-data/betting-markets.html) | Additional props are event-scoped and bookmaker coverage must be observed. Historical requests have separate costs; no request is authorised by reading these pages. |

[Hoop Lab's actual model source](https://raw.githubusercontent.com/joshwilliams332/nba-research/main/site/assets/model.js) was inspected. Minutes times rates, shrinkage and NB distributions are transferable ideas. Its implementation also builds position priors over loaded data, and its missing-teammate backtest helper consults target-game participation; these need independent cutoff checks before any honest as-of replication. We do not copy that implementation or its adjustments. A root LICENSE was not available at the inspected path, so no reuse permission is assumed. Its own README distinguishes typical-line research from retained real-line evaluation.

[Fallas Valverde's write-up](https://github.com/eduardo00-fv/nba-props-model) does not publish its modelling implementation or underlying training dataset. Its [licence](https://raw.githubusercontent.com/eduardo00-fv/nba-props-model/main/LICENSE) restricts reuse; no code, figures or measurements were incorporated. Its calibration write-up explicitly describes fitting on the same evaluation forecasts, so those reported improvements cannot provide independent calibration evidence for this system. We implement disjoint calibration/selection/final dates instead. No self-reported hit rate or return is treated as validation.
